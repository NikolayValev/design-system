# Visions

13 visions across 5 families. Each ships a hand-tuned light
and dark palette and self-hosted faces, and each is held to the same floors — see
[DESIGN.md](../../DESIGN.md) for the rules that apply to all of them.

## Editorial & Print

Warm, typographic, reading-first systems with print-era hierarchy and measured pacing.

- [Editorial](editorial.md) — Publication-grade typography where hierarchy and pacing lead.
- [Quiet Workshop](quiet_workshop.md) — A workshop, not a showroom — one accent, one seam, and type doing the rest.
- [Museum](museum.md) — Print-era discipline and archival warmth for cultivated reading.

## Minimal & Structured

Calm, neutral, disciplined layouts that favour clarity, structure, and breathing room.

- [Swiss International](swiss_international.md) — Grid discipline that turns complexity into structure.
- [Zen Garden](zen.md) — Low-stimulus calm that keeps attention on the task.
- [Clay_Soft](clay_soft.md) — Tactile softness that stays welcoming without losing utility.

## Technical & Utility

Hard edges, monospace rhythm, and high information density for tools and consoles.

- [Terminal](terminal.md) — Command-line certainty rendered as UI.
- [Brutalist](brutalist.md) — Function first — structure over decoration.

## Atmospheric & Luminous

Depth, glow, and cinematic light that use layering and motion to guide attention.

- [Immersive](immersive.md) — Cinematic depth that shapes attention with light and motion.
- [Synthwave](synthwave.md) — Neon drama balanced with clear hierarchy.
- [Noir](noir.md) — High-contrast dark system built for focus and mood.

## Expressive & Statement

Bold, playful, maximal identities built to be memorable and campaign-ready.

- [Solarpunk](solarpunk.md) — Engineered optimism for civic and climate products.
- [Y2K_Chrome](y2k_chrome.md) — Reflective pop futurism with unapologetic energy.
